# README

Quick and very dirty poc to try react with rails via esbuild. Also testing authentication features using rodauth-rails, using sessions and social logins from Rails and React sides.

## Dev server

`bundle install`  
`yarn install`  
`./bin/dev`  

## Sources

Bases on [rails-7-react-typescript-setup](https://ryanbigg.com/2023/06/rails-7-react-typescript-setup).  
Tailwind support: [tailwind with Rails and cssbundling](https://anonoz.github.io/tech/2021/12/11/rails-tailwindcss-svelte.html).  
Rodauth [rodauth with Rails](https://janko.io/adding-authentication-in-rails-with-rodauth).
